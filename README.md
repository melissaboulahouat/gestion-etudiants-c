# Gestion des Étudiants en C

Projet L1 Informatique - Application console en C pour gérer une liste d'étudiants.

## Fonctionnalités
- Ajouter un étudiant (nom, prénom, matricule unique)
- Afficher la liste
- Rechercher par matricule
- Calculer la moyenne sur 3 notes
- Afficher Admis / Ajourn


## Concepts utilisés
- struct, tableau de structures
- fonctions, passage par adresse
- boucles et conditions


### Compilation
gcc main.c -o gestion
./gestion
